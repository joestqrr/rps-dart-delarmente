# Two-Player Rock, Paper, Scissors in Dart

## Name

Radj P. Delarmente

## Course/Year/Section

BSIT 3rd Year - ITE 120

## Description

A console-based two-player Rock, Paper, Scissors game developed in Dart for the IT 120 Laboratory Activity.

## How to Run

Make sure Dart is installed on your computer.

Open the terminal in the project folder and run:

```bash
dart rock_paper_scissors.dart
```

The game will ask both players for their names and moves. It will then display the round result, current score, and final score.
